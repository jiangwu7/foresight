# Reference rig — Nikon Z8 + 24-120 mm f/4 S (spec §7.3) — lab use only

Status: **template (Phase 0)**; documented fully in Phase 2.

Purpose: capture high-quality reference images of the same eyes as the phone adapter for the resolution
experiment (§4.6) and for quality comparison. Never a screening device.

- Same 20D lens and beamsplitter illumination as the adapter.
- Camera at ≈ 0.35 m focusing on the aerial image (0.39× magnification → ≈ 3,500 px across the fundus).
- Same safety rules as `SAFETY.md`. The Z8's low-light performance allows *dimmer* illumination than the
  phone, never brighter.
- Checklist, exposure settings and the alignment procedure: Phase 2.
